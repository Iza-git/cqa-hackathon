# Роль 1 — Бэкенд и интеграция

**Твоя цель:** сервис оценки работает от начала до конца на настоящем Gemini, и контрольный набор
оценён до защиты.

**Твои файлы:** `server.py`, `cqa/store.py`, `cqa/evaluator.py` (вызов модели, без промпта — промпт у роли 2),
`tests/`, `.env`, `README.md` (раздел «Запуск»).

## Уже готово
- Сервер на стандартной библиотеке Python, SQLite, API (см. README → API)
- Оценка через Gemini с JSON-схемой, повторы при 429, темп `GEMINI_RPM`
- Подсчёт итога, N/A, апелляции, версии чек-листа, экспорт CSV, 9 тестов

## Задачи
1. **Ключ Gemini** — получить на aistudio.google.com, вписать `GEMINI_API_KEY` в `.env`.
   Запуск: `python3 server.py` → http://localhost:8000.
2. **Первый настоящий прогон** — оценить 3 диалога (RU, KZ, звонок). Проверить в карточке:
   есть ли цитата, уверенность, «как стоило ответить». Если поля пустые — разобраться в `evaluator.py`.
3. **Прогон всего DEV** — «Оценить все неоценённые». Записать: сколько ошибок, время, стоимость
   (видна внизу карточки) → передать роли 4.
4. **Лимиты** — если много ошибок 429, уменьшить `GEMINI_RPM` в `.env` (по умолчанию 8).
5. **GitHub** — создать открытый репозиторий, запушить, ссылку отправить организаторам.
   Проверить, что `.env` и `data/` НЕ попали в репозиторий.
6. **Час 23** — Данные → «Загрузить набор» → group_id от организаторов → «Оценить все неоценённые»
   → «Скачать результаты CSV».
7. **Час 24** — стоп-код, последний коммит.
