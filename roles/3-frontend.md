# Роль 3 — Фронтенд и UX

**Твоя цель:** каждый шаг демо делается в интерфейсе без запинок и выглядит аккуратно.

**Твои файлы:** `web/index.html`, `web/cqa.css`, `web/cqa.js`. Только чистый HTML/CSS/JS, без фреймворков
(требование задания — компонент должен встраиваться в Dynamics 365).

Цвета и размеры — переменные в начале `web/cqa.css` (`--accent`, `--surface`, …). Меняй их, а не отдельные правила.

## Уже готово
- Экраны: Диалоги, карточка диалога, Апелляции, Аналитика, Чек-лист
- Лента разговора с плеером, переход к реплике с подсветкой цитаты
- Критерии-аккордеон, коучинг, уверенность модели, апелляция прямо в критерии
- Горячие клавиши (`?` — подсказка)

## Задачи
1. **Пройти сценарий защиты руками** (без ключа: `CQA_LLM=mock python3 server.py`):
   список → карточка → «Почему снижена» → «Показать в диалоге» → «Оспорить» → Апелляции → решение
   → итог пересчитан → Чек-лист → изменить критерий → «Переоценить». Записать каждый баг.
2. **Звонки** — открыть `p4-ru-001…005`: длинные транскрипты, проверить ленту и прокрутку.
3. **Узкий экран** — проверить ширину 1280 и 1024 (проектор на защите может быть маленьким).
4. **Пустые и ошибочные состояния** — нет ключа, сервер выключен, диалог без реплик оператора.
5. **Встраивание** — убедиться, что `index.html` работает, если положить `cqa.css` + `cqa.js`
   на другую страницу с `<div id="cqa-app" class="cqa" data-api="http://localhost:8000">`.
