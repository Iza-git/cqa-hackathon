# CQA — Conversation Quality Analytics

Прототип для хакатона Freedom Broker: автоматическая оценка работы оператора по настраиваемому
чек-листу (RU / KZ / EN, чаты и звонки), объяснения со ссылками на реплики, апелляции и пересмотр.

## Запуск (3 шага)

Нужен только Python 3.10+, сторонние пакеты не используются.

```bash
git clone <repo> && cd cqa-hackathon
cp .env.example .env      # впишите GEMINI_API_KEY и CQA_API_URL (ссылка GET из задания, стр. 3)
python3 server.py         # → http://localhost:8000
```

При первом запуске загружается набор DEV. Контрольный набор: «Диалоги» → поле `group_id` →
«Загрузить набор» → «Оценить неоценённые». Результаты можно скачать кнопкой «Экспорт CSV».

Без ключа можно проверить интерфейс на заглушке: `CQA_LLM=mock python3 server.py`.

## Что умеет

| Контур | Функция | Где |
|---|---|---|
| 1 | Редактор чек-листа: критерии, формулировки, вес, тип (Да/Нет, шкала, флаг), N/A с условием, шкалы; версии | «Чек-лист» |
| 1 | Оценка выбранного диалога или всего набора выбранным чек-листом | Карточка, «Диалоги» |
| 1 | По каждому критерию: ответ, баллы, вес до и после перераспределения, объяснение, реплики-доказательства, проверенный участок для пропущенного действия, причина N/A | Карточка |
| 1 | Итог /100, секции, отдельный флаг грубой ошибки, факты о времени (первая реакция, порог 3 мин) | Карточка |
| 2 | Клик по доказательству прокручивает к реплике и подсвечивает её; для звонков показаны время от начала записи и переход к плееру | Карточка |
| 2 | Апелляция: критерий + комментарий | Карточка → «Оспорить» |
| 2 | Проверяющий видит спорную оценку, комментарий, правило и фрагмент диалога, подтверждает или меняет оценку с причиной; итог пересчитывается | «Апелляции» |
| 2 | В карточке видны исходная оценка (зачёркнута), решение и финальный результат | Карточка |

## Архитектура

```
web/            HTML + CSS + JS без зависимостей; компонент монтируется в <div id="cqa-app" data-api="…">
server.py       HTTP API + раздача web/, прокси к API организаторов (решает CORS), пакетная оценка
cqa/evaluator.py  промпт, вызов Gemini (JSON-схема ответа), валидация, предрасчёт фактов о времени
cqa/scoring.py    детерминированный подсчёт: шкала → доля веса, перераспределение при N/A, округление
cqa/store.py      SQLite: диалоги, версии чек-листов, оценки, апелляции
tests/          unit-тесты подсчёта
research/       выгрузка диалогов и шаблон ручной разметки для проверки качества
```

Ключевое решение: **LLM только отвечает на вопросы чек-листа, итог считает код**. Поэтому баллы
воспроизводимы, правила N/A и округления выполняются точно, а при апелляции итог пересчитывается без
повторного вызова модели. Ответ модели проверяется: недопустимый N/A и ступени вне шкалы исправляются
и помечаются предупреждением.

Чек-листы версионируются: каждая оценка привязана к версии, по которой сделана. Новая версия
применяется к набору кнопкой «Переоценить» на странице чек-листа.

**Dynamics 365:** `web/cqa.css` и `web/cqa.js` подключаются как веб-ресурсы, разметка — один `div`.
Стили изолированы классом `.cqa`, адрес сервиса задаётся в `data-api`.

## Модель и стоимость

Gemini 2.5 Flash (`GEMINI_MODEL`), temperature 0, один вызов на оценку диалога. Типичный чат — около
4–6 тыс. входных и 1–3 тыс. выходных токенов (включая рассуждения). По платному тарифу ($0.30 / 1M
вход, $2.50 / 1M выход) это примерно **$0.003–0.01 за оценку**. Точные токены и стоимость каждой
оценки показаны в карточке. На бесплатном тарифе действует ограничение по запросам в минуту, поэтому
пакетная оценка идёт с паузами (`GEMINI_RPM`, по умолчанию 8).

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/dialogs?group_id=` | Список с последней оценкой |
| GET | `/api/dialogs/{id}` | Транскрипт и история оценок |
| POST | `/api/groups/load` `{group_id}` | Загрузить набор у организаторов |
| GET/POST | `/api/checklists`, `/api/checklists/active`, `/api/checklists/{id}/activate` | Версии чек-листа |
| POST | `/api/evaluations` `{conversation_id, checklist_id?}` | Оценить диалог |
| POST | `/api/batch` `{group_id?, only_missing}`; GET `/api/jobs/{id}` | Пакетная оценка |
| GET/POST | `/api/appeals`, `/api/appeals/{id}/decide` `{action, new_answer, reason}` | Апелляции |
| GET | `/api/export.csv?group_id=` | Результаты в CSV |
